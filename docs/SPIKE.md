## What this changes for later milestones

- **MCP SDK 2.x renamed `FastMCP` to `MCPServer`** (`from mcp.server.mcpserver import MCPServer`). Same decorator API. Mounted with `app.mount('/mcp', mcp.streamable_http_app(streamable_http_path='/'))` and `mcp.session_manager.run()` in the FastAPI lifespan.
- **MCP rejects non-localhost `Host` headers (HTTP 421, DNS-rebinding protection).** At deploy time pass `transport_security=TransportSecuritySettings(allowed_hosts=[...])` with the public hostname, or `/mcp` will fail behind Caddy.
- **`algo.maxFlow` returns floats** (`13.0`) and only positive-flow edges. Cast to int in the capacity engine; compute the min cut from the full projected network in Python, as PLAN §7.6 already says.
- **Full-text needs `%term%` (1 edit) or `%%term%%` (2 edits) for fuzzy hits**; a bare misspelling finds nothing. The resolver adds the markers.
- **Write queries are atomic**: a constraint violation undoes every node, edge and SET in that query. Q-EXECUTE can be one query; the preflight read still runs first so the user gets a clean error instead of a constraint exception.
- **`GRAPH.COPY` carries indexes, the full-text index and the unique constraint**, so sandboxes and `world:live` need no schema re-apply.
- **Slow reads are killed at the image's TIMEOUT**; `run_query` should pass an explicit per-query `timeout` and raise when a result has exactly RESULTSET_SIZE rows (truncation is otherwise silent).
